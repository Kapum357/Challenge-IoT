# Challenge-1
Sistema IoT Integrado de Borde para el Monitoreo Hidrometeorológico Local y Alerta Temprana de Desabastecimiento Hídrico en Sabana Centro, Cundinamarca

## Metadatos del Proyecto

- **Proyecto:** Nodo Autónomo de Borde para Monitoreo Hidrometeorológico y Alerta Temprana
- **Ubicación de Referencia:** Provincia de Sabana Centro, Cundinamarca, Colombia (Latitud 4.81° N, Longitud 74.03° W)
- **Versión:** 1.0 — Diseño y Validación Experimental
- **Estándar Metodológico:** ISO/IEC/IEEE 12207 / ISO/IEC 30141 (IoT Reference Architecture)
- **Público Objetivo:** Comités Municipales de Gestión del Riesgo (CMGRD), Juntas de Acción Comunal (JAC), Acueductos Veredales, Ingenieros de Desarrollo IoT
